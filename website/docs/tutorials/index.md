# Tutorials

Learn by doing: a full analysis of real, public data, one step at a time. Each step explains the
idea, shows the code and its real output, and ends with a question to check yourself.
{ .lede }

All tutorials use the public dataset **PAD000040** (Olink Target 96 Inflammation, 142 people with
severe obesity, 2 plates, diabetes status). See [Getting started](../getting-started.md#2-get-example-data)
for the download.
